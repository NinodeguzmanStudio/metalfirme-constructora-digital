# Estructuras Ravichagua

Landing empresarial para fabricacion de estructuras metalicas, mobiliario industrial, barras, rejas y entrepisos comerciales.

## Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Marca y contenido

Los datos principales de marca, contacto, WhatsApp y fotos de proyectos estan centralizados en:

```txt
src/lib/site.ts
```

Dominio objetivo:

```txt
https://www.estructurasravichagua.com
```
